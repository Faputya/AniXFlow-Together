# Совместный просмотр в AniXFlow

Смотрите одну серию одновременно с друзьями — до 5 человек в комнате. Хост выбирает серию и озвучку,
ставит паузу и перематывает; у остальных всё происходит синхронно.

## Как пользоваться

**Хост**
1. Слева в меню нажмите значок «Смотреть вместе» (или кнопку с двумя людьми в плеере).
2. Укажите адрес сервера (один раз, см. [`sync-server/README.md`](../../sync-server/README.md)) и нажмите «Создать комнату».
3. Нажмите «Скопировать приглашение» и отправьте друзьям в любой мессенджер.
4. Откройте любую серию — она сама откроется у всех участников.

**Гость**
1. Скопируйте приглашение, откройте «Смотреть вместе» и вставьте его в поле «Код или ссылка» → «Войти».
   Адрес сервера уже внутри приглашения, вводить его не нужно.
2. Как только хост выберет серию, плеер откроется сам. Если серия скачана — будет играть файл.

Хост может разрешить гостям тоже ставить паузу и перематывать (галочка в окне комнаты).
Серию и озвучку всегда выбирает только хост. Если хост уйдёт, управление перейдёт к следующему участнику;
хост также может передать управление вручную.

## Что и как синхронизируется

| Событие | Что происходит |
|---|---|
| Пауза / продолжение | у всех сразу, на одной и той же позиции |
| Перемотка | все ждут, пока перемотка догрузится у каждого, и стартуют вместе |
| Кто-то буферизуется | остальные встают на паузу («Ждём: Вася»), затем стартуют одновременно |
| Смена серии / озвучки / релиза | у гостей открывается та же серия той же озвучки |
| Скорость воспроизведения | задаёт хост |
| Небольшой уход по времени | подстраивается скоростью ±6 % (незаметно) |
| Большой уход (> 1,2 с) | исправляется перемоткой |
| Обрыв связи | автоматический возврат в комнату и пересинхронизация (место держится 30 с) |
| Вошли посреди серии | догоняете текущую позицию |

Часы участников выравниваются с сервером по замерам ping/pong, поэтому неточные системные часы
на компьютерах не мешают.

## Скачанные серии (офлайн)

Если у гостя серия скачана (та же серия того же релиза), приложение играет файл, а синхронизация
идёт так же, как при онлайн-просмотре. Это можно отключить галочкой «Если серия скачана — смотреть из файла».
Библиотека загрузок не хранит озвучку, поэтому приложение сверяет длительность записи с хостовой:
если расходится больше чем на 3 секунды, у участника появится пометка «другая длина записи» —
скорее всего, скачана другая озвучка или версия.

Если хост запускает серию из раздела загрузок, а у гостя её нет, гость увидит подсказку скачать серию.

## Ссылки-приглашения

Приглашение содержит код и ссылку вида `anixflow-join://КОД?server=…`. Клик по такой ссылке откроет
AniXFlow и войдёт в комнату (приложение регистрирует этот протокол при запуске). Мессенджеры не везде делают
такие ссылки кликабельными — в этом случае просто вставьте приглашение в окно «Смотреть вместе».

В приложении нет личных сообщений между друзьями Anixart, поэтому приглашение отправляется
любым мессенджером.

## Сборка и проверка

Сервер: `cd sync-server && node --test` (41 тест, включая сквозные по настоящим сокетам).
Приложение собирается как обычно (`npm run buildAndMake`). В репозитории уже есть GitHub Actions
`beta-build.yml`: запустите его вручную (Actions → Beta Build Artifacts → Run workflow) — установщик
появится в артефактах прогона.

## Ограничения

- Комнаты хранятся в памяти сервера: при его перезапуске комната закрывается, её нужно создать заново.
- Если у кого-то серия грузится дольше 15 секунд, остальные перестают его ждать.
- Разные озвучки имеют разный тайминг, поэтому гость не может выбрать свою озвучку — только хост.
