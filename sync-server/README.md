# Сервер совместного просмотра AniXFlow

Маленький сервер, через который участники комнаты обмениваются командами синхронизации
(пауза, перемотка, серия, «я загрузился»). **Видео через него не идёт** — у каждого свой
поток или свой скачанный файл, поэтому нагрузка ничтожна: сотни комнат помещаются
в самый слабый бесплатный тариф.

Без зависимостей: нужен только Node.js 18+ (`npm install` не нужен).

```
node server.js          # слушает порт из переменной PORT, по умолчанию 8787
node --test             # тесты
```

Проверка: откройте `http://localhost:8787/health` — должно прийти `{"ok":true,...}`.

## Вариант 1. Проверить сегодня, без регистрации и хостинга

Сервер запускается на вашем компьютере, а наружу его открывает бесплатный туннель Cloudflare
(аккаунт не нужен). Подходит, чтобы попробовать с друзьями; работает, пока открыты оба окна.

1. Запустите сервер: `node server.js`
2. Установите [cloudflared](https://developers.cloudflare.com/cloudflared/install/) и в другом окне выполните:
   `cloudflared tunnel --url http://localhost:8787`
3. В выводе найдите адрес вида `https://что-то-там.trycloudflare.com`.
4. В AniXFlow → «Смотреть вместе» в поле «Адрес сервера» вставьте тот же адрес
   (приложение само заменит `https://` на `wss://`) и создайте комнату.
   Друзьям отправьте приглашение — адрес сервера уже внутри него.

Адрес меняется при каждом запуске туннеля, у Cloudflare для таких туннелей нет гарантий работы.

## Вариант 2. Постоянный бесплатный сервер на Render

1. Выложите папку `sync-server` на GitHub: проще всего форкнуть репозиторий AniXFlow
   с этими изменениями (отдельный репозиторий только с этой папкой тоже подойдёт).
2. На [render.com](https://render.com) войдите через GitHub → **New → Web Service** → выберите репозиторий.
3. Настройки:
   - **Root Directory**: `sync-server` (если выложен весь репозиторий; если только папка — оставьте пустым)
   - **Runtime**: Node
   - **Build Command**: оставьте пустым или `echo ok`
   - **Start Command**: `node server.js`
   - **Instance Type**: Free
   - **Health Check Path**: `/health`
4. После деплоя Render покажет адрес вида `https://anixflow-sync.onrender.com`.
   В приложении используйте его же (оно само превратит в `wss://…`).

Что нужно знать про бесплатный тариф Render (по [их документации](https://render.com/docs/free)):

- сервис засыпает после 15 минут без трафика и просыпается около минуты. Пока идёт просмотр,
  клиенты каждые 5 секунд шлют сообщения, поэтому сервер не засыпает; а если он спал —
  приложение само «будит» его и показывает «Сервер просыпается…»;
- Render может перезапустить бесплатный сервис в любой момент. Комнаты живут в памяти,
  так что при перезапуске комната закроется и её нужно создать заново (просмотр у участников
  при этом не прервётся — только синхронизация);
- 750 бесплатных часов в месяц хватает на один постоянно работающий сервис.

Подойдёт и любой другой хостинг для Node.js с поддержкой WebSocket (Fly.io, Railway, VPS и т. п.) —
достаточно запустить `node server.js` и открыть порт.

## Протокол (для справки)

JSON поверх WebSocket. Клиент → сервер: `ping`, `create`, `join`, `leave`, `play`, `pause`, `seek`,
`rate`, `media`, `ready`, `unavailable`, `meta`, `settings`, `transfer`, `name`, `chat`; настройки комнаты: `guestsCanControl`, `waitForStalls`.
Сервер → клиент: `pong`, `welcome`, `members`, `state`, `settings`, `chat`, `error`.
Состояние комнаты — `{playing, pos, at, rate, ep, waiting}` (`ep` — поколение серии, команды с другим `ep` игнорируются): позиция `pos` была верна в серверный момент `at`,
клиенты считают текущую позицию сами, выравнивая часы по `ping/pong`.

Ограничения: до 5 человек в комнате, 8-символьные коды (6-символьные тоже принимаются), лимиты на размер и частоту сообщений,
не более 20 соединений с одного IP, чат — до 300 символов и 6 сообщений за 10 секунд.
